The foundation

What every layer stands on.

The modules are only as trustworthy as what's beneath them. Preckon's foundation is built for sensitive documents, enterprise scale, and outputs a reviewer can defend.

Multi-tenant isolation

Row-level security separates every client's data. One tenant's documents never touch another's.

Immutable audit spine

Every action and change is recorded — who, what, when — so any number can be traced to its origin.

Provider-independent AI

An orchestrator routes each task to the right model. No lock-in, and no single vendor sees everything.

Construction knowledge graph

Reasoning grounded in real construction logic — elements, assemblies, trades — not generic text.

Human-in-the-loop

Review and correction is built into every layer. Nothing is costed or issued without a person confirming it.

White-labeling

Per-tenant logo and brand color are first-class — run Preckon under your own identity.
