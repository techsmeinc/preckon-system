Questions

The things estimators ask first.

Does this replace our estimators?
No — it removes the manual measuring and the rebuild-from-scratch work so your estimators apply their judgment to more bids. Review is a required step, not an optional one. Nothing is costed or issued without a person confirming it.
How accurate is it?
Every quantity is measured from the drawing and traceable back to the element it came from, so a reviewer can audit any number in a click. Your estimators' corrections are captured, and the system gets sharper on your standards and your project types over time.
What happens to our tender documents?
They stay yours. Data is isolated per tenant, encrypted in transit and at rest, and never used to train shared models. The platform is provider-independent, so no single AI vendor sees everything. More on security →
What file formats can it read?
PDF and CAD drawings, full tender packages, and written specifications. Drop in the set you'd hand an estimator and the platform reads the same documents.
How quickly can we see it on our own project?
Bring one drawing set to the first call and watch it run live, end to end. The Design Partner Program is the fastest way to run real bids through the full chain with the team alongside you.
