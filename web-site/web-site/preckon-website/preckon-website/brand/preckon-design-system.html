02 / TYPE

Grotesk for voice, mono for measure

General Sans speaks; Inter carries the reading; JetBrains Mono carries every measured value. That last rule is the signature — it makes the site read as a measurement instrument, not a brochure.

The rule: anything that is a measured value — area, count, money, code, dimension — renders in mono. 4,820 m², $1,240,500, BOQ-04.12. Prose never does.
