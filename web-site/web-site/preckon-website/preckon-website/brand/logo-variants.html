Preckon logo — which file to use

The original files are drawn in near-black ink (#0B1B2B), which disappears on a dark ground. These are the variants. Every pair below is the same file shown on both backgrounds — the left half is the test the original passes and the right half is the one it fails.

preckon-logo-horizontal.svg — unusable on the right

Dark — for dark grounds

preckon-logo-horizontal-dark.svg — the mirror image: right, not left

Auto — one file, either ground

preckon-logo-horizontal-auto.svg

This one follows your operating system's light/dark setting, not the background it happens to be sitting on — so on this page both halves look the same, and they change together when you switch your OS theme. That is the honest limit of it: it is right for a site that follows the system setting, and wrong for a panel whose colour is fixed regardless. Use the explicit files when you know the ground.

Choosing

WhereFileWhy
The website headernone — it is inline SVG Already correct: it is drawn with var(--ink), so the theme toggle moves it.
A light document, deck or letterheadpreckon-logo-horizontal.svg The original.
A dark deck, a dark email, a video end cardpreckon-logo-horizontal-dark.svg Light ink. The teal is unchanged on purpose — a brand colour that shifts between versions reads as two companies.
A web page that follows the system themepreckon-logo-horizontal-auto.svg One file, no swapping logic.
Figma, Word, PowerPoint, printthe explicit light or dark file None of them evaluate a media query; the auto file falls back to light and would vanish on a dark slide.
Favicon and app iconsunchanged They carry their own dark tile, so they already work on any ground.
